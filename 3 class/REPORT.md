# Three-class next-day AQI model: results and explanation

## Classes

Targets use the repository's HJ 633 AQI labels, collapsed into three operational groups: class 0 Clean is AQI 0–100 (Excellent and Good); class 1 Light-to-moderate is AQI 101–200; class 2 Heavy is AQI above 200. The shared labeler requires 20 valid hourly readings for the daily means of PM2.5, PM10, SO2, NO2 and CO, handles O3 using its trailing eight-hour rule and existing fallback, and computes AQI from pollutant sub-indices. No labeling rules are duplicated here.

## Data source and features

The workflow connects only to MySQL database `air_quality`, using `DB_URL` or `mysql+pymysql://root:@localhost/air_quality`. It uses `all_regions` when present, or available station tables from the 12 named PRSA stations. The selected tables are recorded in the model artifact. It normalizes `interpolated_columns` into the string format expected by `aqi_labels.py`. To prepare the MySQL tables when needed, run `air-quality-classification/notebooks/DB_Connection.ipynb` and `air-quality-classification/notebooks/temp_table.ipynb`. The workflow does not use CSV data.

Today's features are PM2.5, PM10, SO2, NO2, CO, O3 and the eight daily weather summaries TEMP_mean, TEMP_range, PRES_mean, DEWP_mean, RAIN_sum, WSPM_mean, wd_sin and wd_cos. Tomorrow's observed AQI is the target. Tomorrow's weather is not included.

## Method and evaluation

The target date and station rows are ordered chronologically. The first 80% of unique dates form the training period and the final 20% form the untouched test period. Hyperparameters are selected inside the training dates using four expanding-window `TimeSeriesSplit` folds grouped by date. Imputation and scaling are part of each model pipeline, so they are fitted within each fold's training rows. Random Forest, XGBoost and logistic regression are tuned; logistic regression receives log1p transforms for pollutants, rainfall and wind speed. An equal-weight probability average is evaluated as an ensemble. Baselines are persistence (tomorrow equals today's AQI class) and the training majority class. Accuracy confidence limits are bootstrapped over test dates.

The notebook generates `results.csv`, which compares accuracy and its 95% date-bootstrap interval, macro-F1 and within-one-class accuracy for all models and baselines. `per_class.csv` contains precision, recall, F1 and support. `per_station.csv` reports ensemble accuracy by station. `confusion_matrix.csv` contains class counts for each model. Numeric results are generated by running all cells in `three_class_aqi.ipynb` against the connected database; they are intentionally not guessed or filled with synthetic data.

## Results table

See `results.csv` for the complete measured comparison. The expected rough reference is 64–66% accuracy versus about 44% for the majority baseline. If measured accuracy reaches 75% or more, investigate leakage before trusting it. The deployment artifact is selected by held-out accuracy from the ensemble or the best single model, and stores the winning metrics and date ranges.

## Class strengths and weaknesses

Use `per_class.csv` to identify the classes with the highest and lowest precision and recall. Clean days generally dominate historical observations, so majority prediction can score deceptively well while failing to identify severe days. AQI values near 100 and 200 can also shift class at the thresholds, and rare heavy days can yield unstable class-specific metrics. These are empirical patterns to validate against the output tables for the current database.

## Why accuracy is capped

This is a next-day prediction from today's completed conditions. It includes today's observed weather but not tomorrow's weather forecast, which can strongly affect pollutant dispersion, transport and ozone formation. AQI also has day-to-day persistence and abrupt changes that cannot be inferred reliably from these inputs alone. More tuning cannot recover information the inputs do not contain.

## Conclusion

Treat the measured holdout metrics as a historical benchmark, not a health advisory. Meaningfully higher forecasting accuracy requires genuine weather forecasts available at prediction time, then a new leakage-safe training and evaluation run. See the CSV tables for actual performance and per-class limitations.
